使用工具icons_launcher生成的目录

#https://pub-web.flutter-io.cn/packages/icons_launcher
flutter pub get
dart run icons_launcher:create --path <your config file name here>


默认配置文件icons_launcher.yaml
命令：dart run icons_launcher:create

配置文件icons_launcher_dev.yaml
命令：dart run icons_launcher:create --flavor dev

配置文件abc.yaml
命令：dart run icons_launcher:create --path abc
